Weather App
A simple weather application that provides real-time weather data for any location in the world. Built for speed, accuracy, and ease of use.

Features
- Search weather by city.
- Get temperature, humidity, wind speed, and weather conditions
- Real-time data powered by a weather API

Built with C#
API - OpenWeatherMap
